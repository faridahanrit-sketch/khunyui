# ร้านเจ๊เล่ส้มตำ

หน้าร้านลูกค้าและหน้างานแม่อยู่ในโครงการ khunyui เดิมที่เส้นทาง `jele/` ไม่แก้หน้าร้านคุณยุ้ย ระบบกลาง หรือข้อมูลของร้านเดิม

หน้าใช้งานมีเมนู ตัวเลือก ตะกร้า ตรวจรายการ สถานะ งานวันนี้ จัดเมนูและภาพ ยอดรับเงินจริงตามรายการ และวิธีใช้ แม่ใช้ปุ่มเริ่มทำ ทำเสร็จแล้ว และรับเงินแล้ว

## พื้นที่ฝึก

เปิดครั้งแรกเป็นพื้นที่ฝึกที่ระบุชัดบนทุกหน้า บันทึกใน IndexedDB ของเครื่องนั้น และส่งการเปลี่ยนแปลงระหว่างแท็บผ่าน BroadcastChannel ไม่ใช้ข้อมูลตัวอย่างหรือราคาสมมติที่ตั้งไว้ล่วงหน้า มี 18 เมนูตั้งต้นและบัญชีให้เลือกทั้งหมด 80 รายการ ทุกช่องราคาว่างจนผู้ใช้กรอกเอง

รับรายการได้เมื่อกดเปิดขายเมนูนั้นแล้ว เปิดร้าน และเมนูมีราคาครบ เฉพาะตัวเลือกที่มีราคาและของพร้อมจะสั่งได้ รูปใส่เองและบันทึกในเครื่องหลังยืนยัน เมนูรวมต้องระบุส่วนประกอบกับวัตถุดิบก่อนเปิดขาย การปิดวัตถุดิบกระทบจานและตัวเลือกที่ผูกไว้ ไม่ลบรายการที่รับมาแล้ว

การส่งรายการมีรหัสคำขอป้องกันซ้ำ การรับเงินและคืนเงินบันทึกครั้งเดียว ตรวจงานค้างและงานคืนเงินก่อนจบวัน ข้อมูลฝึกและตะกร้าแยกจากร้านจริง การล้างข้อมูลฝึกต้องยืนยัน

## ระบบกลางเดิม

`platform.js` เรียกตารางและฟังก์ชันเดิมของ Supabase สำหรับเมนู ตัวเลือก ภาพ รายการ รับเงิน คืนเงิน และสรุปวัน ตรวจ `store_members` ก่อนเปิดงานร้านและก่อนแก้ข้อมูล ใช้สิทธิ์ของฐานข้อมูลเดิม

`platform-config.js` ใช้เฉพาะ URL และ public anon key ที่มีอยู่ในหน้าเดิม ไม่มี service role key หรือรหัสผ่าน รหัสร้านเจ๊เล่ยังเป็น `null` เพราะยังไม่มีรหัสที่ยืนยันจากฐานข้อมูล ห้ามใช้รหัสร้านคุณยุ้ยแทน และโค้ดป้องกันรหัสนั้นไว้

ก่อนเปิดรับรายการจริง ผู้ดูแลต้องยืนยันร้านเจ๊เล่ในระบบกลาง ผูกบัญชีแม่และใส่รหัสร้านที่ถูกต้องใน config ตรวจสิทธิ์แยกร้านทุกตารางและ Storage และตั้งราคาของรายการที่จะขาย จากนั้นทดสอบระบบจริงด้วยบัญชีที่มีสิทธิ์ การเชื่อมต่อฐานข้อมูลยังไม่ได้ทดสอบในรอบทำหน้าจอนี้

ระบบจริงใช้หน้าจอเดียวกันกับตัวเชื่อมระบบเดิม ส่วนเพิ่มเมนูและกลุ่มใหม่ใช้หน้าเดิม `../#/owner/menu` การปิดวัตถุดิบข้ามเมนูยังต้องเพิ่มการผูกสูตรในฐานข้อมูล จึงแสดงแผงนั้นเฉพาะพื้นที่ฝึก ไม่แสดงเหมือนว่าพร้อมแล้วในร้านจริง

## ตรวจงาน

เรียก `node --test jele/tests/core.test.mjs` จากรากโครงการ หรือ `npm test` จากโฟลเดอร์ jele ทดสอบราคาว่าง ตัวเลือก ของหมด การส่งซ้ำ ราคาในประวัติ ลำดับทำอาหาร รับเงินซ้ำ คืนเงิน และปิดวัน

เปิดผ่านเว็บเซิร์ฟเวอร์ที่รองรับไฟล์โมดูล บน GitHub Pages ใช้ `https://faridahanrit-sketch.github.io/khunyui/jele/` ข้อมูลฝึกอยู่เฉพาะ origin และเครื่องที่เปิด ไม่ใช่ระบบรับรายการจริงหลายเครื่อง

## หน้าตารุ่น 2

เพิ่มพื้นผิว แสงและเงา ปุ่มมีน้ำหนัก สีประจำหมวด และภาพวาดหมวดอาหารที่เขียนด้วยเวกเตอร์ ไม่ใช่ภาพถ่ายอาหารจริง ทุกจานยังเปลี่ยนเป็นภาพที่แม่อัปโหลดเองได้ หมวดลูกค้ามีตามสั่ง ยำ ส้มตำ ของทานคู่ รวมทั้งตัวกรองจานแนะนำและจานพิเศษ หน้าแม่เลือกหมวดเมนูได้และเห็นความพร้อมจากจำนวนจริง ยอดวันนี้รักษารายการเดิมไว้โดยแยกยอดสุทธิ รับเงิน คืนเงิน งานค้าง และเงินที่ยังไม่ได้รับด้วยสีและสัญลักษณ์ ไม่มีการเพิ่มราคาหรือยอดตัวอย่าง และไม่เปลี่ยนการจัดเก็บหรือการเชื่อมต่อร้าน

## การจัดเมนูรุ่น 3

หน้า `#/mother/pending` แสดงรายชื่อรอเปิดขาย แยกยำ ส้มตำ อาหารตามสั่ง และของทานคู่ มี 18 เมนูที่ผู้ใช้ระบุไว้ก่อน และปุ่มเลือกรายชื่อเพิ่มเติมจากบัญชีเดิม 80 รายการ ปุ่มเพิ่มเมนูสร้างรายการชื่อใหม่จริง เลือกหมวด กรอกราคาเมื่อทราบ แก้ชื่อ ย้ายหมวด และเปลี่ยนภาพได้ บันทึกร่างได้โดยยังไม่มีราคาหรือภาพ ไม่สร้างภาพอาหารในรอบนี้

เก็บสถานะเปิดขายแยกจากข้อมูลเมนู การบันทึกชื่อ ราคา และภาพไม่เปิดขายเอง ผู้ใช้กดเปิดขายเมื่อพร้อม และเก็บกลับมารอเปิดขายได้ รายการที่เคยสั่งเก็บชื่อและราคาเดิมไว้ การย้ายจากรุ่นก่อนนำเมนูไปอยู่หน้ารอ โดยเก็บชื่อ ราคา รูป และประวัติเดิมทั้งหมด

นำเพดานไฟล์ภาพ 6 เมกะไบต์ออกจากหน้าจอและที่จัดเก็บ รับภาพแบบเดิมโดยไม่บังคับจำนวนจุดภาพและไม่ย่อหรือบีบอัดต้นฉบับ พื้นที่เก็บจริงยังขึ้นกับเครื่องหรือบริการที่เชื่อมต่อ หากพื้นที่ไม่พอจะแจ้งว่าบันทึกไม่สำเร็จ ฟังก์ชันเพิ่มเมนูร่างในพื้นที่ฝึกทำงานในเครื่องและระหว่างแท็บเดิม ระบบกลางยังไม่ได้ผูกรหัสร้านแม่และยังไม่ได้ทดสอบการเพิ่มร่างข้ามเครื่องในรอบนี้ จึงไม่แสร้งสร้างหรือเปิดเมนูในร้านคุณยุ้ย


## ป้ายร้านรุ่น 4 — รอไฟล์ภาพก่อนเผยแพร่

เตรียมแสดงภาพป้ายที่หน้าร้านและหน้าจัดเมนู ใช้ไฟล์เดียวกันที่
`jele/assets/jele-shop-banner.png` ขนาดภาพต้นฉบับตามภาพที่ผู้ใช้อนุมัติ
ไม่ตัดขอบ ไม่สร้างหรือแก้ภาพใหม่ หากไม่มีไฟล์หรือเปิดภาพไม่ได้ ให้ซ่อนส่วนป้ายและรักษาหน้าเดิมไว้

ปุ่มดูป้ายเต็มเปิดหน้าต่างภาพแยกจากแบบฟอร์มแก้เมนู มีขยาย ย่อ พอดีจอ และเปิดภาพต้นฉบับ
รองรับการเลื่อนภาพเมื่อขยาย ปุ่มแป้นพิมพ์ + − 0 การปิดด้วย Escape และคืนตำแหน่งโฟกัส
ไม่เปลี่ยนข้อมูลเมนู ราคา การเปิดขาย การรับเงิน หรือการเชื่อมฐานข้อมูล

สถานะการส่งงาน: โค้ดเตรียมไว้แล้ว แต่ยังไม่ได้คัดลอกภาพที่ผู้ใช้แนบเข้าที่เก็บโค้ด
เพราะรอบนี้ไม่มีเครื่องสำหรับอ่านไฟล์แนบหรือส่งภาพจากเครื่อง และการส่งเอกสารไป Google Drive
ไม่ได้รับอนุมัติ ไม่ถือว่าใส่ป้ายจริงหรือเผยแพร่แล้ว ก่อนรวมงานต้องใส่ภาพต้นฉบับที่ได้รับอนุญาต
แล้วเปิดทดสอบหน้าร้าน หน้าจัดเมนู และตัวดูภาพบนจอแคบ
