# ร้านเจ๊เล่ — ส่วนเชื่อมระบบจริง

แก้กรณีเปลี่ยนโปสเตอร์แล้วบันทึกเฉพาะในเครื่อง โดยหน้างานจริงส่งไฟล์ต้นฉบับเข้า Storage ของร้าน และบันทึกเส้นทางผ่านฟังก์ชัน set_store_hero_image เดิม การอ่านข้อมูลร้านนำ hero_image_path กลับมาใช้ทั้งหน้าร้านและหน้าจัดเมนู

## การเปลี่ยนแปลง

- เปิดทางระบบจริงเป็นค่าเริ่มต้น ถ้ายังไม่ผูกร้านหรือเชื่อมต่อไม่ได้จะแสดงสถานะนั้น ไม่กลับไปสร้างข้อมูลฝึกโดยอัตโนมัติ พื้นที่ฝึกเดิมยังเลือกแยกได้
- ตรวจสมาชิกที่ยังมีสิทธิ์ก่อนทุกการแก้ไข รวมทั้งการอัปโหลด และปฏิเสธสถานะ รายการ หรือภาพจากรหัสร้านอื่น
- หน้าลูกค้ากรองเมนูเก็บรอเพิ่มเติมจากสิทธิ์ที่ฐานข้อมูลต้องบังคับ
- ลงนามลิงก์ภาพเป็นชุด แยกการอ่านของแม่และลูกค้า และต่ออายุก่อนลิงก์หมดอายุ
- ใช้ตัวดึงข้อมูลเป็นระยะเพียงตัวเดียวและกันการดึงซ้อน ผลอ่านเก่าที่มาถึงช้าจะไม่ทับข้อมูลล่าสุด และผลที่มาถึงหลังออกจากงานร้านจะไม่แสดงข้อมูลแม่กลับขึ้นมา
- หน้ารับเงินจริงแสดงช่องทางตามรายการเดิม และไม่ยืนยันด้วยช่องทางคนละแบบ

## ตรวจแล้ว

ตรรกะเมนูและรับเงินเดิม 17 กรณี ส่วนตัวเชื่อมระบบ 12 กรณี และวงจรโหลดข้อมูล 4 กรณี ผ่านรวม 33 กรณีในระบบประมวลผล JavaScript ที่ใช้ตัวแทนหน้าจอและบริการฐานข้อมูล ไม่ใช่ผลทดสอบกับ Supabase จริงหรือเบราว์เซอร์จริง

ไฟล์ทดสอบที่เพิ่มเรียกได้ด้วย npm test ในโฟลเดอร์ jele เมื่อมี Node.js และระบบรันพร้อม รอบนี้ไม่ได้เรียกคำสั่งนั้นเพราะไม่มีเครื่องประมวลผลสำหรับโครงการ

## ยังต้องทำกับโครงการจริง

รหัสร้านใน platform-config.js ยังเป็น null จนกว่าจะตรวจและยืนยันร้านเจ๊เล่จากฐานข้อมูลจริง ไม่มีการนำรหัสร้านคุณยุ้ยมาแทน ไม่มีการสร้างสมาชิกหรือแก้ฐานข้อมูลในรอบนี้

ต้องเชื่อมบัญชี Supabase แล้วใช้ sql/inspect-existing-platform.sql เพื่อตรวจตาราง สิทธิ์ ฟังก์ชันที่ระบบเดิมเรียก และข้อกำหนดพื้นที่เก็บภาพ ก่อนสร้างหรือปรับร้านเจ๊เล่ สคริปต์นี้อ่านอย่างเดียวและจบด้วย rollback

ส่วนเพิ่มรายชื่อใหม่ที่ยังไม่มีราคาเข้าระบบจริงยังคงปิดไว้ จนกว่าจะยืนยันโครงสร้างและทำการบันทึกร่าง/เปิดขายเป็นธุรกรรมเดียว จะไม่ใช้การสร้างเมนูเปิดขายก่อนแล้วค่อยปิด เพราะข้อมูลอาจถูกอ่านในช่วงกลางได้ ข้อมูลส่วนประกอบและตัวเลือกต้องตรวจจากฐานข้อมูลจริงด้วย

ยังไม่ได้ทดสอบการอัปโหลดภาพ ออเดอร์ รับเงิน หรือสิทธิ์ข้ามร้านกับบริการจริง จึงยังไม่ถือว่าเปิดขายได้ และยังไม่ได้เผยแพร่งานชุดนี้ตามคำสั่งก่อนหน้าที่ให้หยุดการขึ้นเว็บ
